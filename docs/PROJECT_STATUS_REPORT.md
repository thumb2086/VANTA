## 🚀 啟動方式

### 遊戲模式
```bash
# 終端 1：本地伺服器
cd VANTA
python -m tools.godot.serve --ai

# 終端 2：Godot
# 開啟 client/ 按 F5
```

### 訓練模式
```bash
# 同上，遊戲內點「🎯 訓練」
```

### 遠端模式
```bash
# 不需要本地伺服器
# 遊戲內選「一般模式」或「死鬥模式」
# 連線到 Cloudflare Workers
```
