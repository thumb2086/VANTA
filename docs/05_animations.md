# 動畫系統與《特戰英豪》差距分析

> 本文件回答：「有動畫了嗎？」「跟特戰對比，還差什麼？」
> 誠實結論：**本專案原本沒有動畫**（玩家是膠囊、換彈只有計時器）。
> 本輪建立「程序化動畫基礎」，並列出與《特戰英豪》的完整差距。

## 本輪新增（程序化動畫基礎）

### 1. 武器切換系統（動畫的前提，伺服器權威）
- `server/game/inventory.py`：主武器(0)/副武器(1)/刀(2) 三槽位，各自獨立彈匣/後座力
- 切槍立即生效（快照即時反映），切換期間不可開火（長槍 0.65s / 刀 0.45s）
- `ACTION_SWITCH` 封包（Q / 1 / 2 / 3 鍵）

### 2. 協定擴充（驅動客戶端動畫）
- 快照條目 24→25B：`weapon_slot`（u8）+ `reloading` 旗標 → 客戶端由**狀態差異**推斷動畫：
  武器槽位改變 → 換槍動畫；換彈旗標 → 換彈動畫；彈匣減少 → 開火動畫

### 3. Godot 第一人稱視角模型（`weapon_viewmodel.gd`）
- 武器由「武器 JSON 資料」程序化組裝：機匣/槍管/彈匣/握把/槍托/瞄具/刀（箱體零件 + 配色）
- 程序化動畫（時間軸驅動）：
  - **開火後座**（後退+上揚）、**換彈**（放低→退匣→裝匣→拉滑套→回位）、
    **換槍**（放下/抬起）、**切刀揮砍**（弧線）、**步態 bob**（移動擺動）、
    **ADS 瞄準**（移向畫面中心）、**滑鼠晃動**

### 4. 第三人稱程序化角色（`player_rig.gd`）
- 骨架：頭/軀幹/四肢（箱體拼裝，攻守雙色）
- 程序化動作：**步態擺動**（腿依速度正弦擺、手臂反相）、**蹲伏**（降低姿態）、
  **跳躍收腿**、**死亡倒地**（倒下+壓縮）

### 5. 動畫展示場（`client/showcase.tscn` + `showcase.gd`）
- 獨立場景：舞台 + 柱子 + 燈光；1/2/3 切武器、R 換彈、左鍵開火（刀=揮砍）、
  右鍵瞄準、WASD 移動看 bob → **逐項展示每一支動畫**

## 與《特戰英豪》差距清單（誠實）

### ✅ 已有（本輪 + 之前）
| 項目 | 狀態 |
|---|---|
| 換槍（主/副/刀）邏輯 + 動畫 | ✅ 程序化 |
| 換彈動畫（含退匣/拉滑套） | ✅ 程序化（**進度由伺服器驅動**） |
| 開火後座動畫（配合後座力偏移） | ✅ 程序化 |
| 切刀揮砍動畫 | ✅ 程序化 |
| 步態 bob / ADS / 晃動 | ✅ 程序化 |
| 第三人稱步態/蹲伏/跳躍/死亡 | ✅ 程序化 |
| **檢視武器（inspect）動畫** | ✅ 程序化（按 **Y**；F = 撿武器/互動，預留） |
| **換彈動畫-音效精確同步** | ✅ 彈匣落地（mag_drop）於 ~30%、拉滑套（slide_rack）於 ~65%，
  由伺服器權威 `reload_progress` 驅動（不再靠客戶端計時推斷） |

### ❌ 尚未有（真實動畫缺口）
| 項目 | 說明 |
|---|---|
| **骨骼動畫** | 目前是程序化（數學驅動）；特戰是手工製作的骨骼動畫（mocap 級品質） |
| **真 3D 角色模型** | 目前是箱體拼裝；特戰有高面數角色 + 布料/頭髮 |
| **武器模型細節** | 程序化箱體；特戰每把槍有精緻建模 + PBR 材質 |
| ~~inspect（檢視武器）動畫~~ | ✅ 已補上（**按鍵修正：特戰按 Y 檢視、F 是撿武器**） |
| **技能施放動畫** | 每名 Agent 有專屬動作；我們只有粒子 |
| **安放/拆除 Spike 動畫** | 特戰有蹲下操作動作；我們沒有 |
| **ragdoll（布娃娃死亡）** | 特戰死亡是物理 ragdoll；我們是簡單倒下 |
| **受擊反應**（被命中硬直） | 沒有 |

### 如何逐步補齊（路線圖）
1. **glTF 資產**：以 Godot 原生格式匯入低面數角色/武器模型 + 骨骼動畫
   （Blender 產出，或程式化生成骨架），替換箱體拼裝
2. **AnimationTree**：將程序化動畫包成狀態機（idle/run/crouch/jump + 一鍵觸發動畫），
   這是把「程序化」昇華為「可編輯動畫」的橋樑
3. **動畫事件同步**：協定增加 `anim_event` 封包（換彈完成/拉滑套/彈匣落地 → 音效精確對齊）
4. **技能/安放/拆除動作**：為現有技能與 Spike 流程加上第三人稱與第一人稱動作
5. **ragdoll**：死亡時啟用 Godot PhysicalBone3D 模擬

## 執行

```bash
# 動畫展示場（推薦先看這個）
godot --headless --path client showcase.tscn --quit-after 600   # 或直接在編輯器開 showcase.tscn

# 對戰（含換槍/換彈動畫）
python -m tools.godot.serve --ai
godot -e --path client     # F5
# 1/2/3 切槍、Q 循環、R 換彈、左鍵開火、右鍵瞄準

# 測試
python -m pytest tests/test_game_inventory.py   # 武器切換邏輯
```
