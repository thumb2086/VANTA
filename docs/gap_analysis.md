## 詳細差距

### 1. Agent 技能系統（🔴 最大差距）

**Valorant**：每個 Agent 有 4 個獨特技能（C/Q/E/X），有冷卻/充能/消耗機制，技能有實際遊戲效果（煙霧、閃光、治療、偵測等）。

**VANTA**：技能框架已存在（`server/game/abilities.py`、`server/game/spike.py`），但：
- 技能效果僅保留骨架（充能/冷卻未接效果）
- 沒有煙霧/閃光/治療/偵測的實際邏輯
- 客戶端有技能按鍵（Q/E/C/X）但效果是佔位文字

**需要做**：為每個 Agent 實作 4 個技能的效果邏輯 + 客戶端視覺/音效。

### 2. 人物模型與動畫（🔴 視覺核心差距）

**Valorant**：每個角色有獨特 3D 模型、骨骼動畫（idle/run/shoot/reload/death/ability）、表情系統。

**VANTA**：目前是「膠囊 + 膠囊」佔位渲染（`client/scripts/render_world.gd`）。

**需要做**：
- 匯入角色 .glb/.gltf 模型（可從 Mixamo/ReadyPlayerMe 取得免費模型）
- 設定 Skeleton3D + AnimationPlayer
- 製作 idle/run/walk/crouch/shoot/reload/death 動畫
- 第一人稱手臂模型

### 3. 地圖（🔴 戰術核心差距）

**Valorant**：手工設計的戰術地圖（每張有 A/B 兩個安放點、多人通道、戰術位置、高低差）。

**VANTA**：程序化產生的方塊地圖（`tools/maps/generator.py`），有基礎牆壁但無戰術設計。

**需要做**：
- 設計至少 1 張完整戰術地圖（有 A/B site、攻守路線、戰術位置）
- 匯入 3D 地圖模型（Blender 製作 .glb）
- 設定碰撞、光線、遮蔽

### 4. UI 系統（🔴 體驗差距）

**Valorant**：
- 大廳主選單（角色展示+背景粒子）
- 角色選擇畫面（分類篩選、角色詳情、技能預覽）
- 買槍商店（武器分類、價格、護甲）
- 賽後結算（計分板、統計、時間軸、成績對比）
- 進度系統（戰鬥通行證、每日/每週任務）
- 社交面板（好友列表、組隊、聊天）

**VANTA**：有基礎 HUD（準星、血量、彈藥、金錢、回合）和簡單的買槍選單，但缺少完整的 UI 系統。

### 4b. 武器造型與特效（🟡 已於 2026-09 大幅縮小）

**VANTA**：`tools/skins` 產生 14 系列 / 140 造型（colorway + 可平鋪圖案 + 磨損/升級/Chroma），
`tools/vfx` 產生 58 張分層特效藍圖；Godot 端 `SkinRegistry → ProceduralTexture →
SkinMaterial → WeaponFinish` 即時重建材質，`FxManager` 依藍圖播放開火/命中/擊殺特效，
`ScreenFX` 補上創傷相機、FOV 踢動、命中的閃光與擊殺暈影；Armory 可在選單試射與檢視動畫。
外觀完全不進協定（客戶端本機存檔）。

**仍缺**：每日商店輪替與「刷出價格」、角色造型（Agent skins）、槍皮吊飾/玩家卡片等收藏型獎勵、
以及以真實貨幣計價的購買流程（本專案定位是開源學習用，不做付費）。

### 5. 排位與匹配（🔴 進度核心差距）

**Valorant**：Iron → Radiant 排位系統、ELO 分數、匹配算法、賽季重置。

**VANTA**：無任何排位或匹配系統。

### 6. 重播系統（🟡 次要差距）

**Valorant**：完整的對戰重播，含時間軸、視角切換、統計回顧。

**VANTA**：無重播功能（`docs/REPLAY_SYSTEM_DESIGN.md` 有設計文件但未實作）。

## VANTA 的優勢

1. **完全開源**：Valorant 是封閉商業產品，VANTA 可自由修改/分發
2. **伺服器權威**：與 Valorant 相同的防作弊架構
3. **Rust 熱路徑**：性能優於純 Python 實作
4. **Cloudflare Workers**：已可部署到全球邊緣節點
5. **程序化素材**：完整的音效/武器/地圖產生工具鏈
6. **MIT License**：可商用/二次開發
7. **資料驅動的視覺系統**：槍皮/特效規格只寫在 Python 一份，Godot 逐運算式移植，
   並以 `tests/test_tools_skins.py` + `tests/test_tools_vfx_fx.py` 把兩邊釘在一起

## 建議優先順序

1. **P0（ Must have）**：人物模型+動畫 → 讓遊戲「看起來像遊戲」
2. **P0**：至少 1 張完整地圖 → 讓遊戲「玩起來有戰術」
3. **P1**：Agent 技能效果 → 讓遊戲「有特色」
4. **P1**：完整 UI 系統 → 讓遊戲「可操作」（主選單/兵工廠/角色畫廊已就緒，缺賽後結算與社交）
5. **P2**：排位/匹配 → 讓遊戲「可持續玩」
6. **P2**：戰鬥通行證 → 讓遊戲「有動機」
7. **P3**：重播系統 → 讓遊戲「可學習」
8. **P3**：每日商店輪替 + 角色造型 → 讓收藏「有理由回來」
